# MS1-03: UI Prototypes & Wireframes for All User Stories

**Milestone:** MS1  
**Type:** Planning & Documentation  
**Labels:** `backlog` `MS1` `planning` `documentation` `frontend`

## Description

Create paper and/or digital UI prototypes for all user stories (U1-U5) following mobile-first design and Atomic Design principles. Document layout for desktop as well.

## Requirements Addressed

- REQ-008, REQ-009: Content readable on mobile and desktop (U1)
- REQ-022, REQ-023: Mobile-first responsive design (U2)
- REQ-031, REQ-032: Mobile-first responsive design (U3)
- REQ-048, REQ-049: Mobile-first responsive design (U4)
- REQ-069: Atomic Design structure
- REQ-071, REQ-072: Mobile-first and desktop design approach

## Acceptance Criteria

- [ ] U1: Landing page, imprint, about wireframes (mobile-first)
- [ ] U2: Room listing, room card, pagination wireframes
- [ ] U3: Period selection UI variants (2-3 explored), availability feedback
- [ ] U4: Booking form, review step, confirmation wireframes
- [ ] U5: Extended confirmation, directions/contact section, print layout
- [ ] Desktop layouts documented for all screens
- [ ] Atomic Design hierarchy identified (atoms, molecules, organisms)
- [ ] Navigation flow documented
- [ ] Error and empty states shown
- [ ] Prototypes saved in deliverables/ms1/ (PDF, Figma link, or PNGs)

## Dependencies

None — can run in parallel with MS1-01 and MS1-02.

## Implementation Hints

- Use Figma, pen & paper, or prototyping tools
- Focus on user flows: happy path + error cases
- Plan for responsiveness at 375px (mobile), 768px (tablet), 1024px+ (desktop)
- Reference Definition of Done for each user story

## Affected User Stories

U1, U2, U3, U4, U5

## Notes

Prototypes guide frontend implementation in MS2 and validate requirements early.
